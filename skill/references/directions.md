# Directions, concepts and stories

A direction = concept (the idea) + story (the scroll) + style (the look) + signature moment (the memory). Start from the concept; the style follows.

## Axes — make the 3 directions truly different
Each pair of directions must differ on at least 3 of these:

| Axis | Range |
|---|---|
| Energy | still, quiet ↔ loud, kinetic |
| Density | airy, one idea per screen ↔ dense, editorial |
| Temperature | cool, technical ↔ warm, human |
| Surface | flat, graphic ↔ tactile (grain, material, 3D) |
| Type role | invisible, functional ↔ type *is* the image |
| Colour | monochrome ↔ one loud accent ↔ full palette |
| Image source | photography ↔ illustration ↔ 3D ↔ type only |
| Navigation | linear story ↔ explorable / non-linear |
| Era | timeless ↔ retro reference ↔ future |
| Motion | none / restrained ↔ choreographed ↔ interactive / physics |

A useful trio: one **safe-strong** (client will say yes), one **bold** (what the studio would push), one **wildcard** (a different concept, not just a different style).

## Concept and story frameworks
Pick one per direction; the sections follow its beats.
1. **Transformation**: before → tension → turning point → after → invitation. Products, services, renovations, real estate (land → tower).
2. **Chapters / journey**: numbered chapters through a place, process or history. Heritage brands, hospitality, destinations, masterplans.
3. **Object-centric**: one hero object explored from every angle (exploded, cut away, materials, in use). Hardware, cars, watches, architecture.
4. **World / exploration**: a space the visitor moves through (map, diorama, room, island). Games, events, playful brands; needs a plain-nav fallback.
5. **Manifesto**: big statements, few words, type-led, rhythm. Agencies, causes, fashion, founders.
6. **Data story**: numbers that build into an argument; charts that animate with scroll. Fintech, research, impact reports.
7. **Day in the life / ritual**: time of day drives colour and light. Residential, wellness, F&B.
8. **Index / archive**: the work is the story; fast scanning, hover previews. Portfolios, studios, publishers.
9. **Behind the scenes / process**: how it's made, materials, craft. Makers, manufacturers, architects.
10. **Conversation / product demo**: the UI *is* the hero; real flows in motion. SaaS, apps, AI products.

## Direction catalogue
Each: what it is · fits · type ideas (free) · palette approach · motion · signature ideas · avoid.

**Editorial luxury** · magazine-grade layout, generous space, serif display · luxury real estate, hospitality, fashion, jewellery · Bodoni Moda, Instrument Serif, Fraunces + Switzer/Geist · ivory/stone + one deep tone, no gradients · slow (800–1200 ms), soft ease-out, clip reveals · full-bleed image wipes between chapters, kinetic serif headline · avoid cream + terracotta default.

**Swiss / international** · strict grid, asymmetric, type and colour blocks · architecture, design studios, B2B with taste · Schibsted Grotesk, Host Grotesk, General Sans · white + black + one primary · snappy (300–500 ms), grid-aligned slides · grid that rearranges on scroll · avoid hairline-newspaper cliché.

**Kinetic typography** · type is the image, variable fonts in motion · agencies, events, music, campaigns · Anybody, Roboto Flex, Unbounded, Clash Display · high contrast, often 2 colours · scroll-scrubbed axis changes, split-line masks · headline that reshapes with scroll · avoid every heading animating.

**Cinematic 3D object** · one product/object, studio lighting, scroll-driven camera · hardware, auto, watches, real-estate towers · neutral grotesk (Satoshi, Geist) · studio greys + material colour · camera moves between 4–6 beats, exploded views · object assembles/disassembles as you scroll · avoid meaningless blobs and tori.

**Diorama / miniature world** · stylised 3D scene, tilt-shift, toy-like · city projects, masterplans, events, games · rounded display (Funnel Display, Bricolage) · saturated but limited · camera tours between landmarks · masterplan you fly through · needs plain-nav fallback.

**Tactile / material** · paper, grain, fabric, clay; physical feel · craft, food, wellness, stationery · Young Serif, Gambetta, Fraunces (soft axis) · natural pigments · physics-y, springy, hand-made · draggable objects, paper-fold transitions · avoid stock "grain + purple gradient".

**Brutalist / raw** · system fonts, visible structure, unexpected · agencies, artists, publications · monospaced or grotesk at extremes · black/white + one alarm colour · abrupt cuts, no easing · unconventional navigation · must still be readable and accessible.

**Retro-futurist** · 70s/80s sci-fi, chrome, scanlines, technical labels · tech launches, music, gaming · Big Shoulders, Panchang, Tanker · chrome, deep blacks, neon accent used sparingly · CRT-style transitions, counters · boot-up sequence intro · avoid full synthwave pastiche.

**Organic / soft futurism** · blobs grown from data, soft light, glass · wellness tech, biotech, sustainability · Satoshi, Fraunces · desaturated naturals + light · fluid shader backgrounds, slow morphs · living hero shape tied to a real metric · avoid aurora wallpaper.

**Bold colour-block / playful** · flat saturated fields, big shapes, characters · consumer apps, F&B, kids, fintech for youth · Bricolage Grotesque, Syne, Cabinet Grotesk · 3–5 loud colours with rules · springy, bouncy, cursor-reactive · sticker-like elements you can drag · avoid "Memphis" pastiche.

**Dark tech precision** · grids, monospace data, blueprint lines · dev tools, AI infra, security, aerospace · Geist + Geist Mono · near-black with a precise accent (not acid green by default) · line-drawing reveals, number tickers · live system visualisation in hero · avoid the "black + green" default.

**Documentary / photographic** · photography leads, captions, honest · NGOs, journalism, architecture, people-first brands · Instrument Serif + Instrument Sans · from the photos · slow parallax, sequence scrubbing · full-screen photo essay · needs real imagery.

**Glass / spatial UI** · layered translucency, depth, refraction · OS-like product sites, premium apps · Geist, General Sans · light, cool, subtle · depth on scroll, liquid-glass panels (`@samasante/liquid-glass`, Chromium-only refraction) · avoid stacking glass on glass.

**Map / place-led** · the location is the hero · real estate, tourism, events, logistics · Switzer, Schibsted · map-derived palette · camera flights between points · scroll-driven route reveal · keep a list fallback.

**Index / archive** · lists, numbers, hover previews · portfolios, studios, publishers · Geist Mono + a display face · monochrome + image colour · instant hover previews, filter transitions · cursor-following image preview · avoid slow reveals.

**Monumental minimal** · one huge word or number per screen · luxury, architecture, statements · Clash Display, Big Shoulders, Bodoni Moda · 2 colours · scale changes on scroll · headline that zooms into the next section · needs strong copy.

## Signature moments by site type
- **Brand / corporate**: kinetic manifesto headline; values as a pinned story; logo-derived 3D mark that responds to scroll; timeline scrubbed through history
- **Product / SaaS**: real UI zooming out of the hero; feature walkthrough pinned beside live UI; interactive demo in place of a screenshot; number tickers tied to real metrics
- **Real estate / off-plan**: tower or masterplan built up as you scroll; day-to-night lighting slider; location story flying from landmark to site with travel times; unit finder with floor-plan reveal; payment-plan timeline that animates milestones
- **Portfolio / agency**: index with cursor-following previews; project transitions that morph the thumbnail into the case study; WebGL image distortion on hover
- **E-commerce / product launch**: scroll-scrubbed product rotation; exploded view with callouts; colourway switcher that relights the 3D model
- **Event / campaign**: countdown that is also a visual; lineup as kinetic type; explorable venue map
- **Hospitality / F&B**: time-of-day ritual story; menu as tactile cards; ambient video chapters
- **Personal / founder**: manifesto + index; signature handwritten or variable-font name animation

## Copy rules (from the concept)
Write the headline from the concept, not the category. Each section has one job. Plain, specific, active verbs; numbers over adjectives. Real copy from the brief beats lorem ipsum: ask for it, or write a draft and mark it as draft.
